# Operaciones Oriente — LogisticaCD_GUI

Sistema de despacho de productos amazónicos con datos ficticios de demostración. El formulario Swing se encuentra en `src/logistica/Main.java` y `Main.form`.

## Abrir y ejecutar

1. Abra esta carpeta como proyecto Java con Ant en NetBeans (JDK 8 o posterior).
2. Ejecute el proyecto con F6. Para editar la interfaz, abra Main.java y seleccione Diseño.
3. También puede ejecutar `ant jar` y luego `java -jar dist/LogisticaCD_GUI.jar`. Ejecute `ant test` para verificar las estructuras.

## Prueba de entrega

Consulte el inventario ordenado. Registre 15 unidades del producto 850 para Moyobamba. La primera placa asignada será SMO-201. Abra el historial para revisar la entrega. Los datos se mantienen durante la sesión. Las rutas son bidireccionales y sus kilómetros son datos de práctica.
